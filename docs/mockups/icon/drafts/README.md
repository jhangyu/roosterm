# Icon drafts (not chosen)

- A2 Mirrored Session (`a2-mirrored-session.svg`): A host window behind, a client window in front carrying the live prompt: the same tmux session mirrored onto your phone. Midnight tile, teal-to-blue foreground.
- A3 Prompt Beam (`a3-prompt-beam.svg`): The prompt itself as the mark: a heavy chevron and cursor with arcs radiating from the cursor, a command sent over the air. Warm ember tile.
- C2 Hub Asterisk (`c2-hub-asterisk.svg`): Six detached rounded arms around a slate hub form an asterisk-shaped agent mark that also reads as a network node (sessions radiating from one host). A block cursor at the baseline turns it into a live prompt. Light, warm tile.
- C3 Orbit Spark (`c3-orbit-spark.svg`): A cream spark with an orbit ring passing behind and in front of it; the satellite on the ring is your phone reaching the agent from afar. An underscore cursor anchors the terminal reading. Full terracotta tile.
- D1 Paired Panes (`d1-paired-panes.svg`): A handheld pane overlaps a host shell pane: the phone sits in front of the server it drives. The overlap itself is the connection, so the silhouette stays two clear shapes down to 16px.
