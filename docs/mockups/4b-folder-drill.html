Roosterm · Mockup 4b · New session · Folder picker · implementation spec

Drill-down navigator

One folder at a time. A tappable breadcrumb says where you are, a single list shows what is inside, and the folder you are standing in is the folder the session starts in. The dialog opens already inside the last folder you used.

Builds on mockup 3 (calm surfaces): same tokens, dialog and tiles. Shell and Claude Code use the picker; Swarm attaches to an existing socket and keeps the socket list. Section 05 lists every size, state and navigation rule.

Key decisions and trade-offs

  • No second selection step. The current breadcrumb folder is the start folder; the primary button names it (Open Claude Code in roosterm). The remembered folder is preselected, so the common case is one tap.
  • Single list on desktop too, not Finder columns: columns need ≥ 600 px, cannot exist on a 390 px phone, and would fork the component per platform. Desktop gets full keyboard drive instead.
  • Recent folders as chips cover the cross-branch jump a tree gives for free.
  • Dot folders hidden, one tap away; auto-shown for “.” filters and dot paths.
  • Unlistable folders stay selectable with the error shown; only a vanished folder disables Open.
  • Phone: full-height bottom sheet, 48 px segmented session type, 48 px rows, sticky actions above the keyboard.
